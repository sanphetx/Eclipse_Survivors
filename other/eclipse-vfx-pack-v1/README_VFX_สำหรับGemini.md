# ชุดเอฟเฟกต์พิกเซล Eclipse Survivors (VFX Pack v1)

ภาพทั้งหมดในโฟลเดอร์นี้ **สร้างขึ้นใหม่ด้วยโค้ด เป็นของเกมนี้เอง** ไม่ได้มาจากเกมอื่น ใช้และแก้ได้อิสระ รวมถึงตอนเผยแพร่เกม

## สิ่งที่อยู่ในโฟลเดอร์

| ไฟล์ | คืออะไร |
|---|---|
| `sheets/*.png` | สไปรต์ชีต 13 แบบ (เฟรมเรียงแนวนอน 1 แถว) |
| `vfx_manifest.json` | ขนาดเฟรม จำนวนเฟรม fps จุดยึด และโหมดผสมสีของแต่ละเอฟเฟกต์ |
| `vfxAtlas.ts` | **ภาพทั้งหมดฝังอยู่ในไฟล์ TS ไฟล์เดียว** (base64) ไม่ต้องอัปโหลด PNG แยก |
| `vfxPlayer.ts` | โค้ดโหลด สร้าง อัปเดต และวาดเอฟเฟกต์บน canvas |
| `preview_all.png` / `preview_animated.gif` | ภาพตัวอย่าง |

## คำสั่งสำหรับ Gemini

> แนบไฟล์ `vfxAtlas.ts` และ `vfxPlayer.ts` ไปพร้อมกับข้อความนี้ (ถ้าแนบไฟล์ไม่ได้ ให้วางเนื้อหาไฟล์ทีละไฟล์)

```
เพิ่มระบบเอฟเฟกต์พิกเซลจากไฟล์ที่แนบ:

1) สร้าง src/game/vfxAtlas.ts และ src/game/vfxPlayer.ts ตามไฟล์ที่แนบ ห้ามแก้เนื้อหา
2) ใน SimState เพิ่ม `vfx: VfxInstance[]` (เริ่มเป็น []) และเรียก preloadVfx() ครั้งเดียวตอนเปิดเกม
3) ในลูปเกม เรียก updateVfx(sim.vfx, dt) (ใช้ dt ที่หยุดตอนเกม pause)
4) วาด: เรียก drawVfx(ctx, v) สำหรับทุกตัวใน sim.vfx ในขั้นที่วาด sprite ของโลก
   (หลังพื้นและก่อน UI) โดยใช้ transform ของโลกเดียวกับที่วาดมอน
   - magic_circle_* , heal_sparkle ให้วาดในชั้นพื้น (ก่อนตัวละคร) และส่ง squashY: ISO_TILT
   - ที่เหลือวาดหลังตัวละคร
5) จุดที่เรียก spawnVfx(sim.vfx, id, x, y, opts):
   - ตีโดนทุกครั้งที่ติดคริ: 'hit_spark' (scale 1) · ตีโดนปกติ: สุ่ม 30% ของฮิต scale 0.7
   - ฟันเงาของนักฆ่า: 'slash_moon' ที่กลางแนวแดช rotation = มุมแดช scale 1.3
   - ดาบลอยของอัศวินฟัน: 'slash_holy' ที่มอนเป้าหมาย rotation = มุมจากดาบไปมอน
   - อุกกาบาต / ถังระเบิด: 'explosion_fire' scale ตามรัศมีระเบิด (รัศมี/40)
   - ระเบิดวิญญาณจอมมาร: 'explosion_hellfire' scale 0.9
   - ฟ้าผ่า (อาวุธ เสาสายฟ้า ปฏิกิริยา): 'lightning_strike' ที่จุดโดน
   - คลื่นน้ำแข็ง / ปฏิกิริยาแตกละเอียด: 'ice_nova'
   - ตราศักดิ์สิทธิ์นักบุญ: 'magic_circle_gold' lifetime = อายุตรา squashY = ISO_TILT
   - เสาพิพากษา: 'holy_pillar' scale 1.5
   - แผลเลือดแตก / ค้างคาวดื่มเลือด: 'blood_burst'
   - หลุมดำ / ปากตะกละ: 'void_vortex' lifetime = ระยะเวลาสกิล
   - ฟื้นเลือดในแดน / ทุ่งดอกไม้: 'heal_sparkle' ที่เท้าผู้เล่น ทุก 1 วิ
6) ห้ามลบเอฟเฟกต์เดิมที่ทำด้วยโค้ด ให้ใช้ร่วมกัน (ภาพนี้วาดทับ)
7) ตรวจว่า ctx.imageSmoothingEnabled = false ตอนวาดเอฟเฟกต์ (ภาพจะคมแบบพิกเซล)
```

## ปรับเอง
- **ใหญ่/เล็ก:** ส่ง `scale` (พิกเซลยังคม เพราะปิด smoothing)
- **สีอื่น:** เอฟเฟกต์ที่ใช้โหมด `lighter` จะสว่างทับพื้น ถ้าอยากได้สีใหม่ เช่นฟันสีแดง ให้ขอสไปรต์ชีตชุดใหม่ (สร้างได้จากสคริปต์เดิมโดยเปลี่ยนจานสี)
- **จำนวนสูงสุด:** `MAX_ACTIVE = 120` ใน `vfxPlayer.ts` ถ้าเครื่องกระตุก ลดเหลือ 60
