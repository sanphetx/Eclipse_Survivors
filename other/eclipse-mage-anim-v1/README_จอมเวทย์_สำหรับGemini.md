# ท่าตัวละครจอมเวทย์ (Elemental Archmage) — 11 เฟรม

สร้างจากสไปรต์จอมเวทย์ของคุณเอง (64×64) ใช้และแก้ได้อิสระ

## ไฟล์

| ไฟล์ | ขนาด | เฟรม | fps | วน |
|---|---|---|---|---|
| `mage_idle.png` | 256×64 | 4 | 6 | ✔ |
| `mage_walk.png` | 256×64 | 4 | 10 | ✔ |
| `mage_swipe.png` | 192×64 | 3 | 16 | — (เล่นครั้งเดียว) |
| `mageSprites.ts` | — | ทั้ง 3 ท่าฝังเป็น base64 ในไฟล์เดียว (ประมาณ 38 KB) | | |

- ทุกเฟรมหันขวา ถ้าหันซ้ายให้พลิกแนวนอน (`ctx.scale(-1, 1)`)
- จุดยึดที่เท้า: `anchorX = 0.5`, `anchorY = 0.97` (เท้าอยู่ที่แถว 62 จาก 64)
- **ไฟในมือขยับเองทุกเฟรมอยู่แล้ว** ไม่ต้องวาดไฟเพิ่มด้วยโค้ด

## คำสั่งสำหรับ Gemini

> แนบไฟล์ `mageSprites.ts` ไปพร้อมข้อความนี้

```
เปลี่ยนการวาดตัวละครจอมเวทย์ (raceId 'mage' ตอนยังไม่เปลี่ยนคลาส) ให้ใช้ท่าจากไฟล์ที่แนบ:

1) สร้าง src/game/mageSprites.ts ตามไฟล์ที่แนบ ห้ามแก้เนื้อหา
2) โหลดรูปทั้ง 3 ท่าครั้งเดียวตอนเปิดเกม (new Image() แล้วตั้ง src)
3) ใน drawHeroSprite เมื่อเป็นจอมเวทย์ที่ยังไม่มีคลาส ให้เลือกท่า:
   - ถ้ากำลังเล่นท่าปัดมือ (sim.castAnimTimer > 0) → 'swipe'
     เฟรม = min(2, floor((0.19 - castAnimTimer) / 0.19 * 3))
   - ถ้ากำลังเดิน (isMoving) → 'walk' เฟรม = floor(animT * 10) % 4
   - นอกนั้น → 'idle' เฟรม = floor(animT * 6) % 4
   วาดด้วย ctx.imageSmoothingEnabled = false, ขนาดวาดเท่ากับขนาดเดิมของตัวละครในเกม,
   จุดยึดที่เท้า (anchorX 0.5, anchorY 0.97), พลิกเมื่อหันซ้าย
   ท่าโดนตี (hitFlash) ใช้ระบบขาววาบแบบเดิมทับเฟรมนี้ได้เลย
4) ท่าปัดมือ: เพิ่ม sim.castAnimTimer (เริ่ม 0) และฟังก์ชัน triggerCastAnim(sim)
   ที่ตั้ง castAnimTimer = 0.19 ถ้าค่ายังเป็น 0 และผ่านไปแล้วอย่างน้อย 0.4 วิ
   จากการปัดครั้งก่อน (กันปัดรัว)
   ลด castAnimTimer ด้วย dt ทุกเฟรม
   เรียก triggerCastAnim ตอน:
   - ร่ายมหาเวทย์ผสม 3 ธาตุสำเร็จ
   - กด Space (Void Infusion)
   - ท่าไม้ตาย
   ห้ามเรียกตอนอาวุธที่ยิงเองอัตโนมัติ (คทาเวทย์ ลูกไฟ ฯลฯ)
5) ระหว่างท่าปัดมือ ให้หันตัวไปทางที่สกิลออก (พลิกซ้าย/ขวาตามทิศเป้าหมาย)
6) ถ้ารูปยังโหลดไม่เสร็จ ให้วาดแบบเดิมไปก่อน
```

## ถ้าอยากปรับเอง
- **ช้า/เร็ว:** เปลี่ยน `fps` ใน `mageSprites.ts` หรือตัวคูณ `animT` ในคำสั่งข้อ 3
- **ท่าปัดสั้น/ยาว:** เปลี่ยน 0.19 ในคำสั่งข้อ 3–4 (ยิ่งมากยิ่งเห็นท่าชัด แต่ช้าลง)
