# Eclipse Survivors — รีเวิร์กเทพเวลา (Chronos Archon)

> ส่งให้ Gemini ทีละ Task ตามลำดับ · ทดสอบด้วยโหมด "บอท Full" ล็อกคลาสเทพเวลา
> โบนัสดาเมจ % ยังบวกเข้า `dmgIncrease` · ดาเมจสกิลคลาสใช้ `damageMult × classSkillPower`

---

## ภาพรวม: แนวเล่นใหม่

**"สะสมเวลา → หยุดเวลาบ่อยขึ้น → ฆ่าในบ่อเวลา → หยุดเวลาบ่อยขึ้นอีก"**

1. **บ่อเวลา** (สกิลประจำตัวใหม่) หยุดมอนเฉพาะในวง และมอนที่หลุดออกจากวงจะโดน "หนี้เวลา" ระเบิดใส่
2. มอนที่ตายในบ่อ **เร่งคูลดาวน์ของการหยุดเวลาทั้งแมพ**
3. **ลดคูลดาวน์** มีผลกับการหยุดเวลาแรงกว่าคลาสอื่น บิลด์สายลดคูลดาวน์จึงเป็นบิลด์หลักของคลาสนี้
4. **ย้อนกาล** ตายครั้งแรกฟื้นด้วย HP 100% และชาร์จใหม่ได้ด้วยการฆ่าในบ่อเวลา (มีกติกากันโกง)

---

## Task C1: หยุดเวลาทั่วแมพ — นานขึ้น ถี่ขึ้น และโตตามการลดคูลดาวน์

### ค่าใหม่
| ค่า | เดิม | ใหม่ |
|---|---|---|
| คูลดาวน์ | 20 วิ | **16 วิ** |
| ระยะเวลาหยุด | 2.0 วิ | **3.5 วิ** |
| บอสระหว่างหยุด | ช้าลง 65% | ช้าลง 75% |
| ดาเมจระหว่างหยุด | +10% | +15% (บวกเข้า dmgIncrease) |

### กาลเวลาเร่ง (ติดตัวใหม่ของคลาส)
ทุก 1% ของการลดคูลดาวน์ที่ผู้เล่นมี (จากทุกแหล่ง เช่น อัปถาวร นาฬิกาทราย อาร์ติแฟกต์) จะมีผลกับการหยุดเวลาแบบขยาย
```ts
const cdr = 1 - stats.cooldownMult;               // เช่น 0.30 = ลด 30%
const stopCooldown = Math.max(8, 16 * (1 - cdr * 1.5));      // ลดแรงกว่าปกติ 1.5 เท่า · ต่ำสุด 8 วิ
const stopDuration = Math.min(5, 3.5 * (1 + cdr * 0.8));     // นานขึ้นตาม · สูงสุด 5 วิ
```
- ตัวอย่าง: ลดคูลดาวน์ 30% → หยุดเวลาทุก 8.8 วิ นาน 4.3 วิ
- **เพดาน:** หยุดเวลาได้ไม่เกิน 40% ของเวลาทั้งหมด (ถ้า duration/cooldown > 0.4 ให้ยืดคูลดาวน์ออกจนเหลือ 0.4) กันมอนหยุดตลอดเกม
- HUD: นาฬิกาเล็กข้างหลอดพลังคลาส แสดงเวลาที่เหลือก่อนหยุดเวลาครั้งถัดไป

### เมื่อเลือกอัปเกรด
ในตัวเลือกเลเวลอัปของคลาสนี้ ให้ไอเท็มลดคูลดาวน์ (เช่นนาฬิกาทราย Chronos) **ขึ้นบ่อยขึ้น 2 เท่า** และแสดงป้าย "เข้ากับเทพเวลา"

## Task C2: บ่อเวลา (Chrono Well) — สกิลประจำตัวใหม่

### การร่าย
- **ร่ายเองอัตโนมัติทุก 7 วิ** (ใช้ลดคูลดาวน์ได้ ต่ำสุด 4 วิ) ไม่ต้องกดปุ่ม บอทจึงใช้ได้ทันที
- วางที่ **จุดที่มอนหนาแน่นที่สุด** ในระยะ 380px จากผู้เล่น
- เล่นท่าปัดมือ (`triggerCastAnim`)
- รัศมี 120px (คูณพื้นที่สกิลได้) อยู่ได้ 4 วิ · มีพร้อมกันได้สูงสุด 2 บ่อ

### ข้างในบ่อ
| เป้าหมาย | ผล |
|---|---|
| มอนทั่วไป / Elite | **หยุดนิ่งสนิท** เดินไม่ได้ ตีไม่ได้ ยิงไม่ได้ (ยังโดนดาเมจได้) |
| บอส / ยมทูต | **ช้าลง 70%** เท่านั้น (ไม่หยุดสนิท กันบอสตายโดยไม่ได้สู้) |
| กระสุนมอน | **ค้างกลางอากาศ** และสลายไปเมื่อบ่อหมดเวลา (ผู้เล่นใช้บ่อเป็นโล่ได้) |
| มอนที่เดินเข้ามาทีหลัง | หยุดทันทีที่เข้าวง |

**จำกัดจำนวน:** บ่อหนึ่งหยุดมอนได้สูงสุด 40 ตัว ตัวที่เกินจะช้าลง 50% แทน (กันจอเต็มไปด้วยมอนหยุดนิ่ง และกันเกมหนัก)

### หนี้เวลา (Time Debt) — ดาเมจตอนหลุดออกจากบ่อ
- มอนที่ถูกหยุดสะสม "หนี้เวลา" ตามเวลาที่ค้างอยู่ในบ่อ
- ตอนหลุดออก (บ่อหมดเวลา หรือถูกผลักออก) จะ **ระเบิดหนี้เวลาใส่ตัวเอง**:
```ts
const debt = (30 + Math.min(level, 40) * 2.5) * secondsFrozen * stats.damageMult * classSkillPower;
```
- ระเบิดหนี้ **ไม่คิดคริ** และไม่ทำให้เกิดหนี้ซ้ำ
- ภาพ: หน้าปัดนาฬิการ้าวแตกเหนือหัวมอน + เข็มนาฬิกาหมุนย้อน + ตัวเลขดาเมจสีฟ้าอมทอง

### ฆ่าในบ่อ = เร่งหยุดเวลาทั่วแมพ
```ts
// ทุกมอนที่ตายในบ่อ (รวมตายจากหนี้เวลา ภายใน 0.2 วิหลังหลุด)
stopCooldownRemaining -= stopCooldownMax * 0.005;   // ลด 0.5% ของคูลดาวน์เต็ม
// เพดาน: บ่อหนึ่งลดได้รวมไม่เกิน 3 วิ
```
> **หมายเหตุเรื่องตัวเลข:** ที่คุณเสนอ 0.04% ต่อตัว ถ้าคูลดาวน์ 16 วิ จะลดแค่ 0.0064 วิต่อตัว ต้องฆ่าราว 150 ตัวถึงจะลดได้ 1 วิ ผู้เล่นจะแทบไม่รู้สึก ผมเลยปรับเป็น **0.5% ต่อตัว (ประมาณ 0.08 วิ)** และใส่เพดาน **3 วิต่อบ่อ** ฆ่าในบ่อ 20 ตัวจะลดได้ราว 1.6 วิ ซึ่งเห็นผลชัดแต่ไม่ทำให้หยุดเวลารัวจนเกมพัง ถ้าอยากให้แรง/เบากว่านี้ ปรับเลข 0.005 ได้

- เอฟเฟกต์: ทุกตัวที่ตายในบ่อ มีเศษแสงสีฟ้าลอยเข้าหานาฬิกาบน HUD

### ปฏิสัมพันธ์กับหยุดเวลาทั่วแมพ
ระหว่างหยุดเวลาทั่วแมพ บ่อเวลาที่มีอยู่ **ไม่นับเวลาถอยหลัง** (ค้างไว้จนกว่าเวลาจะเดินต่อ) มอนจึงสะสมหนี้เวลานานขึ้น = คอมโบระหว่างสองสกิล

## Task C3: ย้อนกาล (Rewind) — ฟื้นคืนชีพของเทพเวลา

### ทำงานยังไง
- **ครั้งแรกในรอบพร้อมใช้ตั้งแต่เริ่ม**
- โดนดาเมจที่ทำให้ตาย → **ย้อนเวลา**:
  - HP กลับเป็น **100%**
  - ตำแหน่งย้อนกลับไปจุดที่ผู้เล่นอยู่เมื่อ 2 วิก่อน (เก็บตำแหน่งย้อนหลังไว้ทุก 0.1 วิ)
  - อมตะ 2 วิ
  - **หยุดเวลาทั่วแมพทันที** (ไม่ใช้คูลดาวน์)
  - ภาพ: จอเป็นขาวดำ 0.5 วิ เข็มนาฬิกายักษ์หมุนย้อน เสียงเทปกรอกลับ

### ชาร์จใหม่: ต้องฆ่าในบ่อเวลา (กติกากันโกง)
| กติกา | รายละเอียด | กันอะไร |
|---|---|---|
| **จำนวนที่ต้องการเพิ่มขึ้นทุกครั้ง** | ชาร์จครั้งที่ 2 ต้องฆ่า **250** ตัว ครั้งที่ 3 ต้อง **600** ตัว | กันฟื้นได้เรื่อยๆ ไม่จบ |
| **ฟื้นได้สูงสุด 3 ครั้งต่อรอบ** | ครั้งแรกฟรี + ชาร์จใหม่ได้อีก 2 | กันอมตะทั้งเกม |
| **นับเฉพาะมอนที่ถูกหยุดอย่างน้อย 1 วิ** | มอนที่ตายทันทีที่เข้าบ่อไม่นับ | กันการวางบ่อขอบๆ ให้มอนวิ่งผ่านแล้วตาย |
| **นับเฉพาะตอนที่ย้อนกาลยังไม่พร้อม** | ถ้าพร้อมใช้อยู่ ฆ่าเท่าไรก็ไม่สะสม | กันการเก็บสะสมไว้ล่วงหน้า |
| **พักนับ 45 วิหลังฟื้น** | 45 วิแรกหลังฟื้น การฆ่าไม่นับ | กันฟื้นแล้วชาร์จเต็มทันทีกลางฝูง |
| **Elite = 10 ตัว · บอส = 40 ตัว** | มอนทั่วไป = 1 | ให้รางวัลการฆ่าเป้าหมายยาก |
| **ไม่ซ้อนกับฟื้นแบบอื่น** | ถ้ามีหลายแหล่ง (ฟื้นจากลานฝึก ขนนกฟีนิกซ์) ใช้ย้อนกาลก่อน แหล่งอื่นเก็บไว้ครั้งถัดไป | กันฟื้นหลายชั้นในการตายครั้งเดียว |
| **ยมทูต** | ถ้าตายจากยมทูต ย้อนกาลได้ HP แค่ 50% | ยมทูตยังน่ากลัว |

- HUD: ไอคอนนาฬิกาทราย ทรายเต็ม = พร้อมใช้ · ระหว่างชาร์จแสดง "142/250" · ระหว่างพักนับแสดงแม่กุญแจ + เวลาถอยหลัง

## Task C4: ภาพและเสียง

- **บ่อเวลา:** วงกลมบนพื้น (เอียงตาม ISO_TILT) เป็นหน้าปัดนาฬิกาสีฟ้าอมทอง มีเลข 12 ตำแหน่ง เข็มหมุนช้า · ขอบวงมีประกายหมุน · มอนข้างในเป็นสีเทาอมฟ้า (เหมือนภาพนิ่ง)
- **หยุดเวลาทั่วแมพ:** ทั้งจอเป็นโทนฟ้าซีด เสียงทุกอย่างเบาลงและทุ้มลง (lowpass) มีเสียงติ๊กๆ
- **หนี้เวลาระเบิด:** เสียงแก้วแตก + เสียงนาฬิกาเดินเร็ว
- ถ้าต้องการ ภาพวงนาฬิกาทำเป็นสไปรต์ชีตเพิ่มในชุดเอฟเฟกต์ได้ (ขอได้)

## Task C5: ทดสอบด้วยบอท Full

ล็อกคลาสเทพเวลา เล่นด่าน 1 และด่าน 3 อย่างละ 3 รอบ แล้วดูว่า
- [ ] หยุดเวลาทั่วแมพไม่เกิน 40% ของเวลา (ดูจาก log)
- [ ] บ่อเวลาหยุดมอนได้ไม่เกิน 40 ตัวต่อบ่อ และเกมไม่กระตุก
- [ ] บอสไม่ถูกหยุดสนิท
- [ ] ย้อนกาลฟื้นได้สูงสุด 3 ครั้ง และจำนวนที่ต้องฆ่าขึ้นตามตาราง
- [ ] ระเบิดหนี้เวลาไม่ทำให้เกิดหนี้ซ้ำ

**เพิ่ม log ใน Console ทุกนาที:** จำนวนครั้งที่หยุดเวลา · % เวลาที่หยุด · มอนที่ตายในบ่อ · ดาเมจจากหนี้เวลา · สถานะชาร์จย้อนกาล
