# Eclipse Survivors — ออกแบบคลาสใหม่: เผ่ามนุษย์ + เผ่าปีศาจ + แก้ดูดเลือด

> **วิธีใช้:** ส่งให้ Gemini **ทีละงาน** ตามลำดับในหัวข้อ "ลำดับการทำ" ท้ายไฟล์ ลองเล่นหลังจบแต่ละงานก่อนส่งงานถัดไป
> ทุกโบนัสดาเมจ % ในไฟล์นี้ให้ **บวกเข้า `dmgIncrease`** ใน `computeStats` (ระบบจากแพตช์บาลานซ์) ห้ามคูณ `damageMult` ตรงๆ ยกเว้นที่เขียนว่า "ตัวคูณแท้"

**ส่วนที่ทำให้จอมเวทย์ดาบเท่** (เป็นสูตรที่ใช้กับทุกคลาสใหม่ในไฟล์นี้):
1. **มีหลอดพลังให้เห็น** สะสมจากการเล่น (เช่นจำนวนการผสานเวทย์และการฆ่า)
2. **ผู้เล่นได้ตัดสินใจเอง** เช่นยืนนิ่งชาร์จดาบ หรือเลือกธาตุ
3. **มีร่างแปลง** ที่ภาพเปลี่ยนทั้งจอ อยู่ช่วงสั้น และมีชื่อท่าแบบเบียวๆ
4. **มีร่างจุติ** เป็นเป้าหมายระยะยาวภายในคลาส
5. **มีรูปแบบย่อย** (ดาบแต่ละธาตุ) ทำให้เล่นซ้ำแล้วไม่ซ้ำ

### ระบบปุ่มที่ใช้กับทุกคลาส (ทำให้สม่ำเสมอ)
- **แตะ Space** = สกิลประจำเผ่า (มนุษย์: แดช / ปีศาจ: ฝูงค้างคาว)
- **กดค้าง Space 0.5 วิ** = ใช้ท่าไม้ตายของคลาส เมื่อหลอดเต็ม
- **มือถือ**: แตะปุ่ม = สกิลเผ่า และกดค้างปุ่มเดิม = ท่าไม้ตาย (วงแหวนรอบปุ่มจะเติมให้เห็นตอนกดค้าง)

### ระบบการแสดงท่าไม้ตาย (ใช้ร่วมกันทุกคลาส)
ให้ Gemini สร้างฟังก์ชันกลาง `triggerUltimateCutin(sim, titleTh, titleEn, color)` ที่ทำสิ่งต่อไปนี้
- เกมช้าลงเหลือ 20% นาน 0.35 วิ (hitstop)
- จอมืดลง 40% แล้วมีแถบสีของคลาสพาดเฉียงกลางจอ
- ชื่อท่าภาษาไทยตัวใหญ่ พร้อมชื่ออังกฤษตัวเล็กด้านล่าง
- กล้องซูมเข้า 1.08 เท่าแล้วค่อยคืน และจอสั่น 0.3 วิ
- เสียงกระแทกต่ำ ตามด้วยเสียงสูง (เพิ่มใน `sound.ts`)
- ระหว่างร่างแปลง **ย้อมสีจอ** ตามคลาส และมี **หลอดเวลาที่เหลือ** บน HUD

## ส่วนที่ 1: แก้ดูดเลือด "ยืนเฉยๆ ก็ฆ่าได้หมด"

### สาเหตุ (จากโค้ด)
1. **ดูดเลือดจากอาร์ติแฟกต์คิดเป็น % ของดาเมจที่ทำได้** (`effective * cachedLifestealPct` ใน `damageEnemy`) ตอนเลเวล 33 ผู้เล่นทำดาเมจหลายพันต่อวินาที แม้จำกัดไว้ที่ 4% ก็ยังได้เลือดคืนหลักร้อยต่อวินาที
2. **ฮีลจากการฆ่า** (แวมไพร์ หมาป่า เทพความตาย และคลื่นดาบ) โตตามความเร็วในการฆ่า ช่วงท้ายเกมฆ่าได้หลายสิบตัวต่อวินาที
3. **ช่วงอมตะหลังโดนตี (`invulnTimer` 0.5 วิ)** ทำให้ผู้เล่นโดนดาเมจได้แค่ประมาณ **2 ครั้งต่อวินาที** ไม่ว่ามอนจะล้อมกี่ตัว

**สรุป:** ฮีลโตได้ไม่จำกัด แต่ดาเมจที่โดนถูกล็อกไว้ที่ 2 ครั้งต่อวินาที ช่วงท้ายเกมฮีลจึงชนะเสมอ

ที่ถามว่า "ต้องหักเป็น % ไหม" **ใช่ แต่ต้องหักที่การฮีล ไม่ใช่ที่ดาเมจ** วิธีที่เกมแนวนี้ใช้กันคือ **โควต้าฮีลต่อวินาที** คือฮีลจากการดูดเลือดทุกแหล่งรวมกันได้ไม่เกิน X% ของ Max HP ต่อวินาที

### Task 1.1: เพิ่มค่าใน BALANCE (`src/game/data.ts`)
```ts
  // --- ฮีล ---
  leechBudgetPctPerSec: 0.025, // ฮีลจากดูดเลือด/การฆ่า รวมทุกแหล่งไม่เกิน 2.5% ของ Max HP ต่อวินาที
  woundedHealMult: 0.5, // หลังโดนตี ฮีลจากดูดเลือดลดลง 50%
  woundedDuration: 2.0, // นาน 2 วินาที
```

### Task 1.2: ฟังก์ชันฮีลดูดเลือด (`src/components/GameCanvas.tsx`)
เพิ่มใน interface `SimState`:
```ts
leechWindowStart?: number;
leechWindowHealed?: number;
woundedTimer?: number;
```

เพิ่มต่อจาก `const applyPlayerHeal = ...` (นอกคอมโพเนนต์ ระดับเดียวกัน):
```ts
// ฮีลประเภท "ดูดเลือด / ฮีลจากการฆ่า / ฮีลจากการตีโดน" ต้องผ่านฟังก์ชันนี้เท่านั้น
// รวมกันได้ไม่เกิน leechBudgetPctPerSec ของ Max HP ต่อวินาที (เวลาจริง)
const applyLeechHeal = (sim: SimState, rawAmount: number): number => {
  if (rawAmount <= 0 || sim.player.hp >= sim.player.maxHp) return 0;
  const nowSec = performance.now() / 1000;
  if (sim.leechWindowStart === undefined || nowSec - sim.leechWindowStart >= 1) {
    sim.leechWindowStart = nowSec;
    sim.leechWindowHealed = 0;
  }
  let amount = rawAmount;
  if ((sim.woundedTimer || 0) > 0) amount *= BALANCE.woundedHealMult;
  const budget = sim.player.maxHp * BALANCE.leechBudgetPctPerSec;
  const left = Math.max(0, budget - (sim.leechWindowHealed || 0));
  amount = Math.min(amount, left);
  if (amount <= 0) return 0;
  const healed = applyPlayerHeal(sim, amount);
  sim.leechWindowHealed = (sim.leechWindowHealed || 0) + healed;
  return healed;
};
```

### Task 1.3: เปลี่ยนจุดฮีลเหล่านี้จาก `applyPlayerHeal` เป็น `applyLeechHeal`
ค้นหาจากข้อความในโค้ด:
1. ดูดเลือดอาร์ติแฟกต์ใน `damageEnemy`: `const healed = applyPlayerHeal(sim, leechWhole);`
2. ฮีลแวมไพร์ตอนฆ่า: ในบล็อก `if (race.id === 'vampire')` ที่มี `vampireKillCounter`
3. เทพความตาย: `if (Math.random() < 0.25)` → `applyPlayerHeal(sim, 1);`
4. ตัวเร่งธาตุเลือด: `} else if (catalyst === 'blood') {` → `applyPlayerHeal(sim, heal);`
5. ฮีลจากหนามเลือด: `const heal = Math.min(6, 1 + Math.floor(hits / 3));`
6. ดาบเวทย์: `if (hits > 0 && hpLeech > 0)` → `applyPlayerHeal(sim, heal);`
7. ดาบเวทย์ธาตุแสง/เลือด: ที่มี `sim.spellbladeHitHealCooldown = 2.2;`
8. ดาบวิญญาณธาตุแสง: `} else if (sw.element === 'light') {` → `applyPlayerHeal(sim, 1);`
9. ค้างคาวกัด: `if (bitAny && sim.player.hp < sim.player.maxHp) { applyPlayerHeal(sim, 2); }`

**ไม่ต้องเปลี่ยน** (เป็นฮีลประเภทฟื้นฟูหรือรางวัล): ฮีลจากเลเวลอัป ฮีลจากหีบ ฮีลจากไอเท็มเลือดที่ดรอป ฟื้นฟูของนักบุญ ฟื้นฟูของอาร์ติแฟกต์ และฮีลตอนฆ่ายมทูต

### Task 1.4: ฮีลลดลงหลังโดนตี
ทุกจุดที่มี `breakCombo(sim);` (จุดที่ผู้เล่นโดนดาเมจ) ให้เพิ่มต่อท้าย:
```ts
sim.woundedTimer = BALANCE.woundedDuration;
```
และในลูปหลัก ใกล้บรรทัด `if (sim.player.invulnTimer > 0) sim.player.invulnTimer -= dt;` ให้เพิ่ม:
```ts
if ((sim.woundedTimer || 0) > 0) sim.woundedTimer = (sim.woundedTimer || 0) - dt;
```

### ผลที่คาดไว้
ผู้เล่น Max HP 250 จะฮีลจากการดูดเลือดได้สูงสุดประมาณ **6 HP/วิ** และเหลือ 3 HP/วิ หลังโดนตี ส่วนมอนช่วงนาทีที่ 20 ตีครั้งละประมาณ 40+ และโดนได้ 2 ครั้งต่อวินาที ยืนเฉยๆ จะไม่รอดอีก แต่ดูดเลือดยังมีประโยชน์ตอนหลบได้ดี
- ถ้ายังฮีลเยอะไป ลด `leechBudgetPctPerSec` เป็น 0.015
- ถ้าแวมไพร์ไม่สนุก ให้คลาสแวมไพร์ได้โควต้า ×2 (ดูส่วนที่ 3)

## ส่วนที่ 2: เผ่ามนุษย์ (ออกแบบใหม่ 3 คลาส)

> มนุษย์ก่อนเปลี่ยนคลาสท้าทายดีอยู่แล้ว **ไม่ต้องแก้** แก้แค่คลาสเลเวล 20
> ธีมร่วมของมนุษย์คือ **"ใช้แดชเป็นอาวุธ"** ทุกคลาสต้องใช้แดชในแบบของตัวเอง

### 2.1 นักล่า → **นักล่าเงาจันทร์ (Moonshadow Hunter)**
**แนวเล่น:** ติดตราแล้ววิ่งเข้าไปปิดฉาก แดชต่อเนื่องเป็นทอดๆ

**ติดตัว:** ความเร็ว +20% · คูลดาวน์แดช 1.35 วิ

**กลไกหลัก — ตราล่า (Hunt Mark)**
- ลูกธนูของคลาสติด **ตราล่า** ให้ศัตรู ซ้อนได้สูงสุด 5 ชั้น (แสดงเป็นขีดสีเขียวเหนือหัวมอน)
- ลูกธนู: ยิง 3 ดอกทุก 1.6 วิ เหมือนเดิม แต่**วิ่งตามมอนที่มีตราน้อยที่สุด** ลูกใหญ่ขึ้นและมีหางแสงสีเขียวมรกต
- **ตัดเงา (Shadow Cut):** แดชทะลุศัตรูที่มีตรา 3 ชั้นขึ้นไป จะฟันเส้นตรงตามแนวแดช
  - ดาเมจ = `(60 + min(level,40) × 3) × จำนวนตรา × damageMult`
  - ถ้ามอนเลือดเหลือต่ำกว่า `ตรา × 4%` (ไม่ใช้กับบอส) → **ประหารทันที**
  - ประหารได้ → **คูลดาวน์แดชรีเซ็ต** และเกมหยุด 0.08 วิ (hitstop) ผู้เล่นจะแดชต่อเป็นทอดๆ ได้ถ้าเล่นเก่ง
  - ภาพ: เส้นฟันสีขาวอมเขียวตามแนวแดช + เงาซ้อน 3 ร่างตามหลัง
- **หลอดเจตนาสังหาร** (0–30): ประหารด้วยตัดเงา +1, ตัดเงาโดนบอส +3

**ท่าไม้ตาย (หลอดเต็ม + กดค้าง Space) — "ราตรีพันเงา" (Night of a Thousand Shadows)** 8 วินาที
- จอย้อมเป็นสีน้ำเงินกลางคืน มีพระจันทร์เสี้ยวใหญ่ด้านหลัง
- ศัตรูทั้งหมดช้าลง 40%
- คูลดาวน์แดชเหลือ 0.3 วิ ทุกครั้งที่แดชจะมี **เงาแยกร่าง 2 ตัว** แดชในมุม ±35° ไปพร้อมกัน (ตัดเงาได้เหมือนตัวจริง)
- ทุกการตีติดตราเต็ม 5 ชั้นทันที
- **ปิดฉาก "ประหารจันทร์ดับ":** ตอนหมดเวลา ศัตรูที่มีตราทั้งจอจะโดนเส้นฟันพร้อมกัน ดาเมจ = 50% ของตัดเงา × ตรา

**ร่างจุติ — "วิญญาณจันทร์ดับ (Moonless Phantom)"** ปลดเมื่อใช้ท่าไม้ตายครบ 3 ครั้ง
- มีเงาแยกร่าง 1 ตัวติดตัวถาวร ยิงธนูตามผู้เล่น และแดชตามทุกครั้ง
- ท่าไม้ตายนานขึ้นเป็น 10 วิ

### 2.2 นักบุญ → **นักบุญแห่งแสง (Radiant Saint)** — แก้โกเล็มใหม่ทั้งหมด
**แนวเล่น:** สั่งโกเล็มด้วยแดช ให้โกเล็มเป็นกำแพงที่มีตัวตนจริง

**ติดตัว:** Max HP +45 · พื้นที่สกิล +15% · ฟื้นฟู +2 HP ทุก 2 วิ (เหมือนเดิม)

**กลไกหลัก — มหาโกเล็มศิลาทอง**
- **มีหลอดเลือด** = 250% ของ Max HP ผู้เล่น ลดดาเมจที่ได้รับ 60% แสดงหลอดเลือดเหนือหัวโกเล็ม
- **ล่อมอน:** มอนในรัศมี 220px รอบโกเล็มจะเดินไปหาโกเล็มแทนผู้เล่น 60% ของเวลา (สุ่มต่อมอนตอนเข้ารัศมี)
- **ไม่วาร์ปเอง** ถ้าห่างเกิน 600px จะวิ่งกลับด้วยความเร็ว ×2 (ผู้เล่นเห็นว่าวิ่งกลับมา ไม่ใช่หายไป)
- **ถ้าพัง:** แตกเป็นเศษหินพร้อมเอฟเฟกต์ แล้วประกอบตัวใหม่ใน 10 วิ (HUD แสดงเวลานับถอยหลัง ผู้เล่นจะรู้ว่าทำไมไม่มีโกเล็ม)
- ขนาดใหญ่ขึ้น 1.4 เท่า
- **สั่งด้วยแดช — "ก้าวกระโดดศักดิ์สิทธิ์":** ทุกครั้งที่ผู้เล่นแดช โกเล็มจะกระโดดไปลงจุดที่ผู้เล่นแดชออกมา (คูลดาวน์ 4 วิ)
  - ทุบพื้นรัศมี 180px ดาเมจ `(95 + min(level,40) × 4.5) × damageMult × 1.5` สตั๊น 1 วิ ทำลายกระสุน
  - ผู้เล่นจะใช้แดชดึงโกเล็มมาช่วยได้ทันที
- **หลอดศรัทธา** (0–100):
  - โกเล็มรับดาเมจแทน: +1 ต่อ 2% ของเลือดโกเล็มที่เสีย
  - ก้าวกระโดดโดนมอน 5 ตัวขึ้นไป: +5

**ท่าไม้ตาย — "ปฏิญาณแห่งสวรรค์" (Seraph Oath)** 12 วินาที
- โกเล็มลอยขึ้นและงอกปีกแสง 4 ปีก กลายเป็น **"มหาเทวทูตศิลา (Seraph Colossus)"** ซ่อมเลือดเต็ม
- ยิงหอกแสง 8 ทิศทุก 1 วิ (หอกทะลุ)
- ก้าวกระโดดไม่มีคูลดาวน์ จุดที่ลงจะเกิด **วงศักดิ์สิทธิ์** 4 วิ (ยืนในวงฟื้นเลือดเร็วขึ้น และคูลดาวน์อาวุธ -20%)
- ผู้เล่นได้ **รัศมีโล่** กันได้ 3 ครั้ง
- **ปิดฉาก "เสาพิพากษา":** เสาแสงยักษ์ลงกลางโกเล็ม ดาเมจวงกว้าง แล้วโกเล็มกลับร่างเดิม

**ร่างจุติ — "นักบุญผู้ถือดาบสวรรค์ (Saint of the Last Light)"** ปลดเมื่อท่าไม้ตายครบ 3 ครั้ง
- โกเล็มได้ปีกแสงถาวร (ยิงหอกทุก 3 วิ)
- ตอนพังจะระเบิดแสงฮีลผู้เล่น 30% (คูลดาวน์ 60 วิ)

### 2.3 อัศวิน → **อัศวินศักดิ์สิทธิ์ (Holy Paladin)**
**แนวเล่น:** แดชสวนการโจมตี (Parry) ดาบใหญ่ที่เห็นรูปร่างชัด มีน้ำหนัก

**ติดตัว:** เกราะ +7 · Max HP +90 · ดาเมจ +25% (บวกเข้า dmgIncrease)

**กลไกหลัก**
- **ดาบศักดิ์สิทธิ์ (แทนวงคลื่นเดิม):** ทุก 1.8 วิ ดาบวิญญาณสีฟ้าทองยาว 170px **ฟันเป็นเสี้ยวพระจันทร์** 140° ไปทางที่หันหน้า
  - ดาเมจ `(55 + min(level,40) × 2.2 + armor × 4) × damageMult` ผลักแรง จอสั่นเล็กน้อย
  - **ทุกครั้งที่ 3 = "แทงฟ้าผ่า":** แทงตรงเป็นคลื่นแสงยาว 520px ทะลุทุกตัว
  - ภาพ: ต้องเห็นเป็น **รูปดาบ** + รอยเสี้ยวพระจันทร์ค้าง 0.2 วิ (ไม่ใช่วงกลมจางๆ)
- **Perfect Parry:** แดชในช่วง 0.25 วิ ก่อนกระสุนหรือมอนที่กำลังง้าง (`windupTimer > 0`) จะโดน
  - ล้างกระสุนในรัศมี 160px และ **สะท้อนกระสุนกลับ** ไปทางเดิม
  - มอนที่โดน Parry ล้ม 1.5 วิ
  - เกมช้า 0.1 วิ + ข้อความ "PARRY!" สีทอง + วงแสง
  - ฟันดาบศักดิ์สิทธิ์ทันที 1 ครั้ง ดาเมจ ×2.5 (ตัวคูณแท้ของท่านี้เท่านั้น)
- **Aegis Stance:** มอนในระยะ 100px ทุกตัว ให้เกราะ +1 (สูงสุด +8)
- **หลอดเกียรติยศ** (0–100): Parry สำเร็จ +15 · ฆ่ามอนด้วยดาบ +0.5 · โดนตีขณะมีเกราะ Aegis +3

**ท่าไม้ตาย — "เอ็กซ์แคลิเบอร์ลงทัณฑ์" (Excalibur Descent)** 10 วินาที
- ดาบยักษ์สีทองตกลงจากฟ้ามาปักข้างหน้า ทำดาเมจรัศมี 260px แล้วอัศวินดึงดาบขึ้นมาถือ
- ดาบศักดิ์สิทธิ์ใหญ่ขึ้น 2.5 เท่า ทุกการฟันปล่อย **คลื่นแสง** ทะลุยาว 600px
- เกราะ +10 ต้านแรงกระแทก 100%
- **ปิดฉาก "ดาบพิพากษา":** ฟันลงตรงๆ เกิดรอยแยกแสงยาวทั้งจอ

**ร่างจุติ — "ราชันอัศวินแห่งแสง (Lionheart King)"** ปลดเมื่อ Perfect Parry ครบ 25 ครั้ง
- ดาบศักดิ์สิทธิ์ใหญ่ขึ้นถาวร 1.4 เท่า
- Parry สำเร็จจะเรียกเอ็กซ์แคลิเบอร์ขนาดเล็กลงมาปักทันที

### 3.1 จอมมาร (Demon Lord) — **เพลิงนรก + จำนวนการฆ่า**
**แนวเล่น:** ยิ่งฆ่ามาก ไฟยิ่งลาม ลามจนกลายเป็นนรกทั้งจอ

**ติดตัว:** ดาเมจ +22% · Max HP +35 · ทุกการโจมตีติด **เพลิงนรก**

**กลไกหลัก**
- **เพลิงนรก (Hellfire):** ทุกฮิตติดไฟ 1 ชั้น (สูงสุด 5) ไหม้ชั้นละ `(4 + min(level,40) × 0.4) × damageMult` ต่อวินาที นาน 3 วิ
  - ไฟสีส้มดำ ต่างจากไฟธรรมดา
  - ไม่นับเป็นฮิตของคอมโบ (กันคอมโบพุ่งเกิน)
- **ระเบิดวิญญาณ:** มอนที่ตายขณะติดไฟ จะระเบิดรัศมี 90px และแพร่ไฟ 2 ชั้นให้มอนรอบๆ **ไฟลามเป็นทอดๆ** ตามจำนวนการฆ่า
- **บัญชีวิญญาณ:** ตัวนับการฆ่าแสดงบน HUD (ตัวเลขสีเพลิง) ปลดพลังตามจำนวนในรอบนั้น
  | ฆ่าครบ | ปลดล็อก |
  |---|---|
  | 100 | **รอยเพลิง:** เดินแล้วทิ้งรอยไฟบนพื้น 2 วิ |
  | 300 | **ฝนเพลิงนรก:** เสาเพลิงตกใส่กลุ่มมอนหนาแน่นทุก 4 วิ |
  | 666 | **มงกุฎอเวจี:** ระเบิดวิญญาณกว้างขึ้น 50% และแพร่ไฟ 3 ชั้น มงกุฎไฟลอยเหนือหัว |
- **หลอดอเวจี** (0–150): มอนที่ตายขณะติดไฟ +1
- **คืนชีพ (ของเดิม) เปลี่ยนเป็น "ฟื้นจากเถ้าถ่าน":** ตายแล้วฟื้นด้วย HP 55% และ **เปิดท่าไม้ตายทันทีฟรี** (คูลดาวน์ 2 นาที)

**ท่าไม้ตาย — "ประตูนรกเปิด" (Gate of Inferno)** 10 วินาที
- พื้นแตกเป็นลาวา จอย้อมสีแดงส้ม จอมมารงอกปีกเพลิงและเขา
- มอนบนจอทั้งหมดติดไฟเต็ม 5 ชั้นทันที และไฟไหม้แรงขึ้น ×2
- ทุกการฆ่าจะเรียก **อิมป์เพลิง** วิ่งพุ่งชนมอนใกล้สุดแล้วระเบิด (มีพร้อมกันได้สูงสุด 12 ตัว)
- **ปิดฉาก "อุกกาบาตอเวจี":** อุกกาบาตเพลิงยักษ์ตกกลางจอ ดาเมจ = ผลรวมไฟที่ไหม้มอนตอนนั้น × 3

**ร่างจุติ — "มหาจอมมารแห่งอเวจีที่เจ็ด (Archfiend of the Seventh Hell)"** ปลดเมื่อฆ่าครบ 2,000 ตัวในรอบเดียว
- ร่างเพลิงถาวร: ปีกไฟ + รอยเพลิงกว้างขึ้น
- ระเบิดวิญญาณทุกครั้งมีโอกาส 10% เรียกอิมป์เพลิง

### 3.2 แวมไพร์ (Vampire Lord) — **เลือด หลอด HP ความเสี่ยง กลางวัน/กลางคืน**
**แนวเล่น:** เลือดน้อย = แรงและไวขึ้น ฮีลต้อง "ไปดื่ม" เอง ไม่ใช่ได้ฟรี

**ติดตัว:** ความเร็ว +15% · ได้โควต้าฮีลดูดเลือด ×2 (เฉพาะคลาสนี้)

**กลไกหลัก**
- **กระหายโลหิต (Bloodlust):** ทุก 10% ของ HP ที่หายไป ได้ดาเมจ +5% และความเร็ว +3%
  - ที่ HP 20% จะได้ดาเมจ +40% ความเร็ว +24% (บวกเข้า dmgIncrease)
  - HUD: ขอบจอแดงขึ้นตาม HP ที่หายไป และหัวใจเต้นเร็วขึ้น
- **แผลเลือด (Bleed):** ฮีลตอนฆ่าแบบเดิมเอาออก ให้ทุกฮิตติดแผลเลือดแทน (สูงสุด 3 ชั้น ไหลเลือด 3 วิ)
- **งานเลี้ยงโลหิต (Crimson Feast):** ตอนแปลงเป็นฝูงค้างคาว ค้างคาวที่บินผ่านมอนมีแผลเลือดจะ **ดื่มแผลทั้งหมด**
  - ฮีลชั้นละ 0.8% Max HP (ผ่านโควต้าดูดเลือด)
  - ดาเมจระเบิดเลือด = ชั้นแผล × `(20 + min(level,40)) × damageMult`
  - **ฮีลจึงต้องเข้าไปเสี่ยงเอง ไม่ได้ฟรีจากการยืน**
- **ราคาโลหิต:** ใช้ฝูงค้างคาวได้แม้หลอดโลหิตไม่เต็ม โดยจ่าย HP 8% แทน (ใช้แล้ว HP ไม่ลดต่ำกว่า 1)
- **โล่โลหิต:** ฮีลที่เกิน Max HP กลายเป็นโล่ สูงสุด 25% ของ Max HP ลดลง 2% ต่อวินาที
- **กลางวัน / กลางคืน (ใหม่)**
  | | กลางคืน "จันทร์สีเลือด" | กลางวัน "แสงตะวันแผดเผา" |
  |---|---|---|
  | ผล | แผลเลือดไหลแรง ×2 · คูลดาวน์ฝูงค้างคาว -40% | ฮีลทุกแหล่ง -50% |
  | ชดเชย | — | กระหายโลหิตแรงขึ้น ×1.5 (เลือดน้อยแล้วแรงกว่าเดิม) |
  - กลางวันจึงเป็นช่วง "เลือดน้อยแต่ตีแรง" เสี่ยงสูงได้ผลตอบแทนสูง
- **พิธีสุดท้าย (Last Rite):** HP ลดต่ำกว่า 15% ครั้งแรกในรอบ 60 วิ → อมตะ 1.5 วิ + ระเบิดเลือดรอบตัว (ไม่ฮีล ให้เวลาหนี)

**ท่าไม้ตาย — "ราตรีโลหิตนิรันดร์" (Eternal Crimson Night)** ใช้ได้เมื่อหลอดโลหิตเต็ม **และ HP ต่ำกว่า 50%** · 12 วินาที
- **บังคับเป็นกลางคืนทันที** (เวลากลางวัน/กลางคืนหยุดนิ่ง) จอย้อมแดงดำ พระจันทร์สีเลือดเต็มดวง
- แปลงร่างเป็นเจ้าแห่งแวมไพร์ ผ้าคลุมกลายเป็นปีกค้างคาว
- ฝูงค้างคาวใช้ได้ทุก 1.5 วิโดยไม่จ่ายอะไร
- ฝนหอกเลือดตกใส่มอนที่มีแผลเลือด
- โควต้าดูดเลือด ×2 อีกชั้น (รวมเป็น ×4)
- **ปิดฉาก "สนธยาโลหิต":** มอนที่มีแผลเลือดทั้งจอระเบิดพร้อมกัน

**ร่างจุติ — "เคานต์โลหิตนิรันดร์ (Eternal Count)"** ปลดเมื่ออยู่ที่ HP ต่ำกว่า 25% รวมครบ 60 วิในรอบเดียว
- กระหายโลหิตนับเพิ่มอีก 1 ขั้นถาวร
- พิธีสุดท้ายคูลดาวน์เหลือ 40 วิ

### 3.3 7 บาป (Seven Sins) — **ผู้อัญเชิญบาปทั้งเจ็ด**

**แนวเล่น:** สะสมสัญญากับบาปแต่ละตัว บาปแต่ละตัวแรงขึ้นจากการกระทำที่ตรงกับบาปของมัน

#### คำตอบเรื่อง "ออกมาแปปๆ หรืออยู่ตลอด" → **ใช้แบบผสม**
- **พันธสัญญา (อยู่ตลอด):** อัญเชิญค้างไว้ได้ **สูงสุด 3 ตัว** มีหลอดเลือด ถ้าตายจะกลับมาใน 12 วิ
  - ผู้เล่นมีตัวตนบนจอให้ผูกพัน และวางแผนได้ว่าจะเลือกตัวไหน
- **พิธีบาปทั้งเจ็ด (ชั่วคราว):** ท่าไม้ตายเรียกบาป **ครบทั้ง 7 ตัว** มาพร้อมกัน 12 วิ ตัวที่ยังไม่มีสัญญาจะมาที่เลเวล 1
  - ได้ภาพความยิ่งใหญ่ตอนเรียกครบ
- ถ้าให้อยู่ตลอดทั้ง 7 ตัว จอจะรกและแรงเกินไป ถ้าให้ออกมาแปปๆ ทั้งหมด จะไม่รู้สึกว่าเป็นผู้อัญเชิญ แบบผสมจึงได้ทั้งสองอย่าง

#### การได้บาป
- เลเวล 20 เลือกบาปตัวแรกจาก 3 ตัวสุ่ม
- ทุก 5 เลเวลหลังจากนั้น เกิด **"ทำสัญญาบาป"** เลือก 1 ใน 2 ตัวเลือก
  - ทำสัญญากับบาปตัวใหม่
  - หรืออัปบาปที่มีอยู่ (เลเวล 1–3)
- ถ้ามีสัญญาครบ 3 ตัวแล้วเลือกตัวใหม่ ต้องเลือกว่าจะ "ส่งกลับ" ตัวไหน (ตัวที่ส่งกลับยังเก็บเลเวลไว้ ใช้ในพิธีบาปทั้งเจ็ด)

#### ติดตัวของคลาส
ดาเมจบาปทุกตัว = ค่าของบาป × `damageMult` ของผู้เล่น · Max HP +30

**หลอดบาป (0–100):** เติมจากพลังบาปของทุกตัวที่มีสัญญา (แต่ละตัวเติมจากเงื่อนไขของตัวเอง) **ยิ่งมีหลายบาป หลอดยิ่งเต็มไวและหลากหลาย**

**ท่าไม้ตาย — "พิธีบาปทั้งเจ็ด" (Rite of the Seven Sins)** 12 วินาที
- วงเวทย์ 7 แฉกบนพื้นรอบตัวผู้เล่น ฉายสัญลักษณ์บาปทีละจุด
- **บาปทั้ง 7 ตัวผุดขึ้นจากวงพร้อมกัน** ตัวที่มีสัญญาจะได้ +1 เลเวลชั่วคราว
- **ปิดฉาก "วันพิพากษาแห่งบาป":** บาปทั้ง 7 ยิงลำแสงสีของตัวเองเข้าหาผู้เล่น แล้วผู้เล่นปลดปล่อยคลื่นสีรุ้งดำออกไปทั้งจอ ดาเมจขึ้นกับจำนวนบาปที่มีสัญญา

**ร่างจุติ — "ราชาแห่งบาปที่แปด (Sovereign of the Eighth Sin)"** ปลดเมื่อเคยทำสัญญาครบทั้ง 7 บาปในรอบเดียว
- สัญญาค้างได้ 4 ตัว
- ผู้เล่นมีออร่าเงา 7 สี ทุก 10 วิจะเรียกบาปสุ่ม 1 ตัวที่ไม่ได้มีสัญญามาช่วย 5 วิ

#### หมายเหตุทางเทคนิคของบาป
- บาปทุกตัวใช้ระบบเดียวกัน: `x, y, hp, maxHp, level, respawnTimer, aiTimer` เก็บใน `sim.sins: SinEntity[]`
- มอนในรัศมี 160px ของบาปที่มีเลือด จะหันไปตีบาป 30% ของเวลา (ช่วยเป็นกำแพงเบาๆ)
- เลือดของบาป = 120% ของ Max HP ผู้เล่น (โลภะ 60%, เกียจคร้าน 200%)
- ฮิตของบาปนับเป็นคอมโบของผู้เล่น
- **ทำทีละตัว:** เริ่มจาก โอหัง (ใช้โค้ดเดิม) → โทสะ → ตะกละ → ตัวที่เหลือ

## ส่วนที่ 4: ลำดับการทำ (ส่งให้ Gemini ทีละข้อ)

1. **ส่วนที่ 1** แก้ดูดเลือด (Task 1.1–1.4) → ลองเล่นว่ายืนเฉยๆ ไม่รอดแล้ว
